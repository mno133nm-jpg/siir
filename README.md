# سير AI Telegram Bot V1

بوت Telegram للتوظيف: تحليل CV، Career Profile، Job Match، وتجهيز وإرسال إيميلات التقديم.

## تشغيل سريع
1. انسخ `.env.example` إلى `.env`.
2. ضع `BOT_TOKEN` من BotFather.
3. ضع `OPENAI_API_KEY`.
4. ضع `RESEND_API_KEY` و`FROM_EMAIL`.
5. شغّل `npm install` ثم `npm start`.

## ملاحظة الإنتاج
لنسخة SaaS الحقيقية استبدل `data/db.json` بـ Supabase/PostgreSQL وأضف Usage Limits واشتراك Pro.
